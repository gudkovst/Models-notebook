# OCR Practice

## Практикум по распознаванию исторических текстов

---

## 1. Что можно делать

- Выбирать одну из пяти OCR-моделей.
- Распознавать изображения отдельных текстовых строк.
- Распознавать все изображения из выбранной папки.
- Сохранять результаты распознавания в CSV.
- Дообучать готовые модели на собственных изображениях.
- Проверять результаты дообучения.
- Сохранять лучшие и последние веса модели.
- Продолжать обучение после закрытия программы.
- Сравнивать распознавание до и после обучения.
- Просматривать графики изменения функции потерь.

Обучение нейронной сети с нуля в этот практикум не входит.

---

## 2. Системные требования

Для работы необходимы:

- Компьютер с Windows 10 или Windows 11 (64-bit).
- Python 3.12 (64-bit).
- Подключение к интернету для первоначальной установки библиотек.
- Свободное место на диске для TensorFlow, JupyterLab и моделей.
- Желательно не менее 8 ГБ оперативной памяти.

Наличие видеокарты не обязательно.

Все основные операции можно выполнять на процессоре (CPU).
Дообучение на CPU может занимать значительное время.

## 3. Установка Python

Если Python 3.12 уже установлен, переходите к следующему разделу.

1. Откройте сайт:

   https://www.python.org/downloads/

2. Найдите версию Python 3.12 для Windows.

3. Скачайте 64-разрядный установщик.

4. Запустите установку.

5. Рекомендуется включить опцию:

   `Add Python to PATH`

6. Завершите установку.

После установки Python желательно перезагрузить компьютер.

**Важно:** для этого учебного комплекта используется Python 3.12.
Другие версии Python могут быть несовместимы с установленными библиотеками.

## 5. Первоначальная установка

Установка выполняется только один раз.

### Шаг 1

Распакуйте комплект в удобную папку.

Например:

```text
C:\OCR_Practice
```

Рекомендуется использовать путь без русских букв и специальных символов.

### Шаг 2

Откройте папку комплекта.

### Шаг 3

Дважды щёлкните:

`install_windows.bat`

Программа автоматически:

1. Найдёт установленный Python 3.12.
2. Создаст виртуальное окружение `.venv`.
3. Установит необходимые библиотеки.
4. Проверит TensorFlow.

Во время установки потребуется подключение к интернету.

**Не закрывайте окно установки до появления сообщения об успешном завершении.**

Установка может занимать несколько минут.

### Шаг 4

После успешной установки закройте окно установщика.

### Шаг 5. Проверка окружения

Запустите:

`check_environment.bat`

Программа покажет версии установленных библиотек.

Основные компоненты:

- Python 3.12.
- TensorFlow 2.16.2.
- NumPy 1.26.4.
- OpenCV 4.11.0.
- JupyterLab.

Если проверка завершилась успешно, можно начинать работу.

---

### Шаг 6. Запуск JupyterLab

Для начала работы дважды щёлкните:

`start_jupyter.bat`

Откроется окно командной строки.

Через некоторое время в браузере должен открыться JupyterLab.

Если браузер не открылся автоматически, наберите в поисковой строке
адрес:

http://localhost:8888/lab

**Не закрывайте окно командной строки, пока работаете в JupyterLab.**

---

### Шаг 7. Выбор OCR-модели

В ноутбуке найдите ячейку:

```python
MODEL_NAME = "filled_long"
```

Доступны пять моделей:

- `filled_long` — обучена на основных предварительно обработанных строках
- `filled_short` — обучена на коротких (из бокового столбца) обработанных строках
- `first20str1` — обучена на коротких и основных строках
- `long_first_20str` — обучена на основных строках
- `short_first_20str` — обучена на коротких строках

Чтобы выбрать другую модель, измените значение `MODEL_NAME`.

Например:

```python
MODEL_NAME = "filled_short"
```

Затем выполните ячейку.

Разные модели могут давать разные результаты на одном изображении.

## 8. Распознавание одного изображения

Поместите изображение в папку:

`data/test`

Например:

`data/test/1647_filled.jpg`

В ноутбуке найдите настройку:

```python
IMAGE_PATH = "data/test/1647_filled.jpg"
```

Укажите путь к своему изображению.

Выполните ячейки просмотра изображения и распознавания.

На экране появится распознанный текст.

**Важно:** модели предназначены для изображений отдельных
текстовых строк, а не целых страниц.

Если у вас есть изображение страницы рукописи, сначала необходимо
разделить её на отдельные строки.

## 12. Подготовка данных для дообучения

Для дообучения нужны изображения отдельных текстовых строк
и правильные транскрипции этих строк.

Транскрипции хранятся в отдельных TXT-файлах.

Пример:

```text
133601-180.jpg
133601-180.gt.txt
```

В файле `133601-180.gt.txt` должен находиться правильный текст,
изображённый в `133601-180.jpg`.

Имена изображения и транскрипции должны совпадать
до расширения `.jpg` и суффикса `.gt.txt`.

Переименовывать существующие файлы такого формата не требуется.

TXT-файлы должны быть сохранены в кодировке UTF-8.

### Обучающие данные

Поместите обучающие пары в папку:

`data/train`

### Проверочные данные

Поместите проверочные пары в папку:

`data/validation`

## 13. Дообучение модели

Откройте в ноутбуке раздел настройки дообучения.

Основные параметры:

```python
TRAIN_MODEL_NAME = "filled_long"

EXPERIMENT_NAME = "experiment_001"

EPOCHS = 3

LEARNING_RATE = 0.00001

RESUME = False
```

Назначение параметров:

`TRAIN_MODEL_NAME` — модель, которую будем дообучать.

`EXPERIMENT_NAME` — название эксперимента.

`EPOCHS` — количество эпох обучения.

`LEARNING_RATE` — скорость изменения весов модели.

`RESUME` — продолжать существующее обучение или начать новый эксперимент.

Во время обучения программа будет выводить значение CTC loss.

---

## 14. Сохранение результатов обучения

Все результаты сохраняются отдельно от исходных моделей.

Например:

```text
results/
    finetuned_models/
        filled_long/
            experiment_001/
                best/
                latest/
                history.json
                settings.json
```

Папка `best` содержит контрольную точку с лучшим результатом
по validation loss.

Папка `latest` содержит последнее сохранённое состояние обучения.

Файл `history.json` содержит историю изменения функции потерь.

Файл `settings.json` содержит настройки эксперимента.

**Исходные модели из папки `models` не перезаписываются.**

## 15. Продолжение обучения

Если обучение уже выполнялось, его можно продолжить.

Для этого в ноутбуке предусмотрен отдельный раздел 11.

Укажите:

```python
RESUME_MODEL_NAME = "filled_long"

RESUME_EXPERIMENT_NAME = "experiment_001"

ADDITIONAL_EPOCHS = 2
```

Название эксперимента должно совпадать с названием
ранее сохранённого эксперимента.

После запуска программа восстановит последние веса модели
и состояние оптимизатора.

Затем выполнит указанное количество дополнительных эпох.

Например, если ранее выполнено 3 эпохи,
а вы указали ещё 2, программа выполнит эпохи 4 и 5.

## 16. Использование дообученной модели

После завершения обучения откройте раздел выбора
дообученной модели.

Укажите:

```python
FINETUNED_MODEL_NAME = "filled_long"

FINETUNED_EXPERIMENT = "experiment_001"

CHECKPOINT_TYPE = "best"
```

Можно использовать:

- `best` — лучшие сохранённые веса.
- `latest` — последние сохранённые веса.

После загрузки модели можно распознавать изображения
и сравнивать результаты с исходной моделью.

Дообучение не всегда приводит к улучшению распознавания.

На результат влияют количество изображений, качество разметки,
состав обучающих данных и параметры обучения.

---

## 17. Графики обучения

В ноутбуке предусмотрен просмотр графиков CTC-loss.

На графике отображаются:

- Train loss — ошибка на обучающих данных.
- Validation loss — ошибка на проверочных данных.

Если training loss уменьшается, а validation loss увеличивается,
это может свидетельствовать о переобучении.

Для оценки реального качества OCR желательно также сравнивать
распознанный текст с правильными транскрипциями.

## 19. Частые проблемы

### Python не найден

Убедитесь, что установлен Python 3.12 (64-bit).

При необходимости переустановите Python и включите
опцию добавления в PATH.

После установки повторно запустите `install_windows.bat`.

### JupyterLab не открывается

Убедитесь, что установка завершилась успешно.

Запустите `check_environment.bat`.

Затем повторите запуск `start_jupyter.bat`.

### Изображение не найдено

Проверьте путь к изображению.

Например:

`data/test/example.jpg`

Убедитесь, что файл действительно находится в указанной папке.

### Не найдена транскрипция

Для каждого обучающего изображения должен существовать
соответствующий файл `.gt.txt`.

Например:

```text
example.jpg
example.gt.txt
```

### Неизвестные символы в транскрипции

Разные OCR-модели используют разные наборы символов.

Если транскрипция содержит символы, которых нет в алфавите
выбранной модели, программа остановится с сообщением об ошибке.

Проверьте транскрипцию и выбранную модель.

Не рекомендуется автоматически удалять неизвестные символы:
это может исказить обучающие данные.

## 20. Некоторые замечания

1. Не удаляйте исходные модели из папки `models`.

2. Не используйте одну и ту же папку эксперимента
   для разных независимых запусков обучения.

3. Для нового эксперимента задавайте новое значение
   `EXPERIMENT_NAME`.

4. Не изменяйте файлы контрольных точек вручную.

5. Перед длительным обучением проверяйте правильность
   изображений и транскрипций.

6. Регулярно сохраняйте важные результаты.

7. Не закрывайте JupyterLab во время выполняющегося обучения.
